Для использования программы необходимо:
1) Задать исходный файл и целевой файл
2) Указать необходимые листы в исходном и целевом файле
3) Указать диапазон ячеек, кнопка диапазаон работает пермонентно
4) Нажать кнопку пернести данные
5) При правильном вводе пойдет шкала прогресс бара и в конце выдаст сообщение о успешном переносе
6) Проверяем целевой файл.
